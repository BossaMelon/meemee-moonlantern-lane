# 原型素材来源

- 像素画资产由 A01 独立美术任务维护在 `assets/pixel/**`，来源、尺寸、透明信息及用途以该目录内的 manifest 为准。P02 不覆盖该目录。
- `game/ui/shop_canvas.gd` 只负责加载并以 nearest 采样显示图像，不再绘制旧代码矢量店景。真正资产尚未挂接时会明确显示缺图提示，不能将提示界面视为美术完成。
- `game/ui/main.gd` 使用系统中文字体回退：苹方、微软雅黑、Noto Sans CJK SC、Heiti SC。字体由运行平台提供，本仓库不复制或分发系统字体。Mac 运行和截图不能证明 Windows/iOS 字体及安全区已验收。
- 界面边框、颜色和焦点框是原创 UI 样式；没有复制其他游戏的 UI 图片。
- 当前无音乐/音效占位，未引入来源不明的媒体。
