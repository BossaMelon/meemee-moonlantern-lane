# 咩咩与月灯巷

**MeeMee & Moonlantern Lane**

为咩咩制作的单人魔法经营游戏。目标是温暖、有发现感、有经营深度，让玩家主动想“再营业一天”。开发工作由 agent 承担。

## 当前状态

2026-10-25：完成初步竞品研究、设计探索与接手路线；尚未实现游戏、安装依赖或确定最终引擎。“上头”是待验证的目标，不是已经证实的效果。

本轮按用户要求仅交付文档，由其他 agent 负责后续实现。

## 已确定的方向

- 中文名《咩咩与月灯巷》，英文工作名 MeeMee & Moonlantern Lane。
- 参考英式魔法街巷与学校生活的氛围，使用原创角色、地点和魔法物件。
- 经营是主体；不是必须做食堂；当前主推魔法奇物杂货铺。
- 重点参考《星露谷》《东方夜雀食堂》《菜市场模拟器》和《潜水员戴夫》。用户已明确“疯狂戴夫”指《潜水员戴夫》。
- 纯 agent 开发，不等于运行时必须调用大模型，也不代表自动化测试能替代人的趣味判断。
